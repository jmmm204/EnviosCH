# EnviosCH

Sistema de gestión logística desarrollado en Java utilizando el framework OpenXava y el paradigma MDA 
(Model Driven Architecture). El proyecto modela la operación de Envíos CH en Nicaragua, permitiendo la 
administración de almacenes, agentes aduanales y paquetería especializada. Implementa herencia JPA, 
propiedades calculadas para tarifación dinámica y reglas de negocio automatizadas.
